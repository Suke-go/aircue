# 起動時の「回る気配＋空気砲」

初回起動では6秒で2周する回転音と、右→左→右→左の空気砲を配置済みにします。全体7秒。保存済みのプロジェクトがある場合は、その作業を復元します。素材とプロジェクトは実行ファイルに内蔵し、初回に素材をdata/assetsへ展開します。

orbit-source.wavは本プロジェクト向けに合成した息・衣擦れ風の音源（48 kHz、ステレオ、6秒）です。立体音響は再生・書き出し時に既存のKEMARレンダラーで適用します。

空気砲は図5(a)のb=1を基にした負100 ms→正100 msの矩形二相波です（計200 ms）。標準波形の「SHITARA 矩形二相波 b=1」からも選択できます。旧試作の12+48 ms波形を置き換えました。駆動開始は右1050／左2550／右4050／左5550 ms。負→正の切替を音が側方を通る1150／2650／4150／5650 msに合わせています。到達遅延は未補正です。

図5の電圧は−10 V→＋10 V、§7.1の方向実験はb=1、距離1 m、振動板変位8.2 mmです。アプリでは時間構造と相対振幅を実装し、初期レベルは−18 dBFSです。実機の電圧・変位・空気圧は再現／校正していません。設置距離30 cmは従来の仮値です。音との到達同期には、左右それぞれの実測遅延分だけ駆動開始を前へ移動してください。新しい部品を含むプロジェクトにはこの更新版AirCueが必要です。

参考: Kojima, Shitara et al., SHITARA, January 19, 2023, p.8 Fig.5(a), pp.16–17 §7.1.
