# イヤホン向け立体音響の設計 — v0.5.0

## 目的と画面

音声ファイルとテスト音を使い、音源の方位・高さ・距離・移動を編集して試聴する。立体音響は任意で、オフなら元のステレオ音声を保持する。空気砲の駆動波形とは独立して作り、最後に共通タイムラインへ配置する。

「波形作成」「オーディオ」「タイムライン」「出力設定」は同じTauriウィンドウ内で切り替える。空気砲の共通素材に左右の属性を追加しない。物理出力の割り当ては、どの編集画面からも上部の出力設定へ移動して変更できる。

オーディオ画面の左側に音源、切り出し、再生時間、レベル、プレビューを置く。右側に定位プリセット、平面図、高さの推移、経路の確認スライダー、移動・通過点の編集を置く。図上の点を選び、そのままドラッグして方位と距離を変更できる。高さはスライダー、数値、時間・高さのグラフから編集する。グラフの横方向は通過時刻、縦方向は仰角とする。図にフォーカスした状態では左右キーで方位、上下キーで距離を調整する。

## 音源とプリセット

- ファイル: WAV、MP3、FLAC、OGG Vorbis、M4A AAC/ALAC、AIFF。取り込み上限128 MB・10分、64素材。48 kHzステレオに変換してコピーする。
- テスト音: 正弦波、三角波、矩形波、ホワイトノイズ、周波数スイープ。周波数20〜16,000 Hz。
- 定位プリセット: 正面、右、後方、左、周回、左→正面→右、頭上を通過、正面から接近。
- 定位プリセットは音源・音声レベル・再生時間を保持し、位置と移動だけを設定する。選択時に立体音響をオンにする。
- 1クリップ20 ms〜60秒。ファイルの開始位置を末尾へ寄せた場合は、残りの長さに再生時間を収める。

## 座標・移動

| 項目 | 定義 |
|---|---|
| 方位 | 正面0°、右+90°、左−90°、後方±180° |
| 仰角 | 耳の水平面0°、下限−40°、上限+90° |
| 距離 | 0.3〜5 m。図の半径は操作しやすい表示尺度で、縮尺図ではない |
| 固定 | 単一の方位・仰角・距離 |
| 周回 | 方位を一定速度で回す。−360〜+360°/s |
| 指定位置まで移動 | 旧版互換の方位の線形移動。仰角と距離は固定 |
| 経路を編集 | 開始・通過点・終了の方位、仰角、距離を補間 |

経路は2〜32点。各点の時刻はクリップ内の割合 `at`（0〜1）で保持し、画面ではmsで編集する。開始は0、終了は1に固定し、隣の点から全長の0.1%以上離す。再生時間を変えると点の実時刻が比例して伸縮し、位置と経路の形は変わらない。

通過点の追加は確認スライダーの位置に行う。端点や既存点に近い場合は、最も広い区間の中間へ追加する。追加位置は既存経路上から計算するため、追加だけでは経路を変えない。開始と終了は削除できない。

経路の方位は短い側の円弧で補間する。170°から−170°へ移動すると後方を20°で横切る。ちょうど180°の差は入力の符号に従う。高さと距離は線形補間する。旧版の「指定位置まで移動」は以前の長い側も含む補間を保持する。

「経路の確認」は任意時刻の位置を視覚的に確認する機能で、音声のシークではない。プレビュー中は再生時刻に追従し、停止中は選んだ確認位置を保持する。

## 編集補助

左右反転は方位と回転方向を反転する。逆順は経路の開始・終了と時間順序を反転する。周回と旧版の指定位置移動にも適用できる。等間隔は通過点の位置を保ち、時刻を均等に置く。終点を始点に合わせる操作は経路の終点の位置だけを置き換える。

オーディオの編集履歴は最大40段階。取り消し後の新規編集でやり直し履歴を破棄する。図の1回のドラッグを1段階として扱う。音源の読み込み、別クリップの編集、別プロジェクトを開く操作では履歴をリセットする。再起動をまたぐ履歴保存とタイムライン全体のUndoは対象外。

## 音声処理

立体音響オンでは左右を平均して単一音源とし、MIT KEMARの測定HRIRを畳み込んでイヤホン左右を生成する。48 kHz・140タップのデータを使用する。最大384サンプルの処理区間で位置を評価し、フィルターをサンプルごとに補間する。経路の通過時刻では区間を分割する。距離によるゲインもサンプルごとに補間する。

距離係数は `1 / max(1, distanceM)`。1 m以内では距離による増幅を加えない。空間内の反射、遮蔽、ドップラー効果、近距離HRIR、頭部追跡は含まない。仰角・前後の定位には個人差があり、プリセット名は設定する軌道を表すもので知覚の保証ではない。データの出典と条件は `THIRD_PARTY_HRTF.txt` に記録する。

プレビュー中の編集は再レンダリング後に短いクロスフェードで反映する。古い編集結果が新しい結果を上書きしないよう世代を管理する。長いクリップでは反映まで遅延がある。繰り返し再生では終点から開始へ戻るので、連続した移動には始終点を揃える。

プレビュー、オーディオWAV書き出し、タイムラインは同じRustレンダラーを使用する。音声レベルは−60〜+12 dB、クリップ補正は−60〜+24 dB。0 dBFS超過は再生・書き出し時にエラーにし、自動正規化はしない。値はデジタルゲインであり、実測dB SPLや空気砲の体感強度ではない。

## タイムラインと保存

クリップは音源ID、切り出し、レベル、定位設定、経路のコピーを持つ。素材を共有するクリップでも経路は個別に編集する。「音源・位置を編集」で開き、「クリップを更新」で選択クリップへ反映する。「複製」は設定と補正を保持して直後へ置く。60秒を超える配置は拒否する。

立体音響をオフにしても経路を保存し、再びオンにすれば再利用できる。オフ中の位置編集操作は無効化する。新しい音声素材を通常配置した際の初期値もオフとする。

プロジェクトのJSONに `keyframes` を追加する。旧v0.2.0の欠落フィールドは空配列として読み、固定・周回・旧移動を維持する。外部ファイルを開くときも、点数・範囲・有限値・時刻順序をRust側で検証する。音声ファイルを含むプロジェクトの持ち運びは `.aircue` と同名の `.media` フォルダーをセットにする。

## 検証と今後の範囲

共通JSONの位置テストをJavaScriptとRustの両方で実行し、後方の境界、途中点、周回、旧版の移動を照合する。保存互換、距離減衰を含む音声出力、立体音響オフ時の左右保持をRustで確認する。UIは分離したテストデータで、プリセット、図のドラッグ、通過時刻、タイムラインへの配置・複製・再編集を確認する。

以上の編集補助・保存・レンダリングはv0.4.0で実装済みで、v0.5.0では同じ完成音響を実験試行から再生できるようにした。実機での定位評価、ND90-8・A07の空気砲測定・校正、流体モデル、個人化HRTFは別の実装・検証範囲とする。Unityへの完成音響・経路情報の書き出しは [Unity連携設計](UNITY_INTEGRATION.md)、試行との同期は [実験連携](EXPERIMENT_SYNC.md) にまとめる。
